# 本机固定代码签名

macOS 打包脚本通过 `tools/release/prepare_signing.py` 读取本机签名配置。
固定签名材料保存在项目根目录的 `.local-signing/`：独立钥匙串保存私钥，
`identity.json` 保存证书指纹和钥匙串路径，`keychain-password` 用于自动解锁。
目录权限必须为 700，密码文件为 600；该目录已加入 `.gitignore`，不得提交到仓库或放进安装包。
`identity.json` 使用相对钥匙串路径，移动整个项目时无需修改绝对路径。

每次打包复用同一证书，不会重新创建身份。缺少配置或解锁失败时构建停止。
CI 或其他机器可显式设置 `AISUBPRO_CODESIGN_IDENTITY` 与
`AISUBPRO_CODESIGN_KEYCHAIN` 使用其预先配置的签名身份。
本地证书只用于本机更新身份连续性，不等同于 Apple Developer ID 或公证。

备份或移动本机项目时，必须连同隐藏目录 `.local-signing/` 一起保存；仅 Git 克隆不会包含签名材料。
保留此目录中的钥匙串和配置；删除或更换证书可能再次触发凭证访问授权。
旧版临时签名的凭证在首次迁移时仍可能需要用户确认。签名稳定不代表所有
系统权限都永久有效。恢复或换机时应通过受保护的备份迁移，不能重新生成
证书并宣称身份仍然相同。

构建前会把项目钥匙串登记到用户搜索列表首位。若旧位置存在同名且同证书指纹的副本，只替换该登记项，保留其他钥匙串；不会删除旧文件。随后使用项目保存的密码解锁，并为专用钥匙串内的签名密钥配置 Apple 工具分区授权。仅复制钥匙串文件而不更新系统登记，可能使 codesign 继续访问锁定的旧副本并弹出密码请求。
