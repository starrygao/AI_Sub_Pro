# 功能审查修复：知识库、媒体就绪与恢复

本轮对应 `ce4469b` 的功能审查，修复数据保存、任务调度、交付恢复和控制台状态问题。

## 行为变化

1. 知识库未修改的编辑表单在返回时刷新；未保存草稿保留。控制台全量保存携带编辑时的 `expected_state`，服务端在知识库编辑锁内比较，冲突返回 409，避免覆盖刚确认的术语或恢复已删除记录。
2. 明确确认同源术语的新译名时实际更新审定译文，后续翻译提示词采用新值；写入成功后才标记候选已入库。保存前的旧读取请求不能覆盖保存结果、反馈或后续读取状态。
3. 连续发现同路径视频变化时继承旧字幕归属标记，稳定后仅备份本程序生成且未被用户改动的旧字幕，防止新视频误用旧字幕。
4. qB 普通下载按候选所对应的单文件进度判定；整季其他集未完成不再阻塞已完成单集。校验、搬移、缺失、错误、未知状态读取失败和上传/整理/VTrans 保护仍有效。只查询当前候选关联的文件列表，其他种子保持保守目录阻塞。
5. 已通过导出认证而仅写回失败的任务记录发布重试阶段，重试保留同一项目与已生成字幕，再次校验视频指纹及交付认证。源视频变化或产物失效仍拒绝发布；认证失败不会被标为可直接发布的重试。
6. 音轨语言未知且 TMDB 失败的条目独立退避，候选 SQL 在分页前排除未到重试时间的条目。实际候选以最久未检查为先，优先级仅打破相同时间的平局，防止 100 个下载阻塞条目长期压住后面的就绪文件。
7. Emby 刷新从全部待刷新条目中分页选择，失败批次轮转，不再只处理最新 50 个完成任务。
8. 列表与详情轮询在已有请求未完成时不重复启动周期请求；用户切换筛选或项目仍可以发起新请求，旧响应不能覆盖新上下文，失败后继续轮询。
9. 发布等待阶段优先显示实际阻塞原因；取消只更新进度消息和阶段，保留实际记录的百分比，未记录时继续显示未知。
10. 已更新三个受影响 JS 文件的静态资源版本，刷新后台即可载入本次修改。
