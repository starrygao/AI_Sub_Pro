# 2026-09-23 审查修复

本次修复覆盖审查发现的十项问题，保留“仅新增、同目录同名双语 SRT、不烧录、不覆盖已有字幕”的处理规则。

| 问题 | 修复后的行为 |
| --- | --- |
| 编辑知识库使已完成字幕失效，或导致运行中任务无法发布 | 每次翻译固定知识库和候选术语快照；翻译、润色、QA、交付校验使用同一份快照。下一次翻译读取新知识。编辑知识库前，仅为原认证有效的历史已完成任务补快照，不修复无效认证。 |
| 音轨全局序号被误用于音频相对序号 | 为 `0:a:N` 保存音频相对序号，排除导评，优先外语对白及原声音轨。 |
| 外挂或内嵌部分字幕被作为完整翻译源 | 统一排除 forced、foreign、commentary 及中文强制／导评标记；外挂标签去掉视频主名后再判断。 |
| 标题标记 Forced 的中文轨道使视频被跳过 | 仅完整中文字幕使任务跳过；简繁文本、PGS 等图形字幕均覆盖。同名英文 SRT 冲突在中文轨道检查之后处理。 |
| 连续保存监控目录时新请求被旧扫描覆盖 | 每次请求保存独立 revision；扫描完成后验证 revision，再安装基线和目录。取消与 B→C→B 场景也可正确处理。 |
| 影视知识库前缀匹配盖过精确片名 | 优先 TMDB 身份、精确片名；仅未知片名时才按文件名回退匹配。 |
| 第二次下载就绪查询短暂异常变成永久错误 | 保留等待状态，上游恢复后自动重新检查。 |
| TMDB 电视剧重试缺少年份回退 | 初次查询与手动重试复用同一逻辑，限定年份无结果后再查无年份。 |
| 缺失进度被显示成 0% | 库任务 API 保留未知值；任务列表区分未知、实际 0% 和完成 100%。 |
| 登录后无法回到知识库 | 允许 `#knowledge` 作为登录目的页，并更新登录脚本缓存版本。 |

另外补充了 MKV 内明确标记为中文、非空且类型可信的 SRT／ASS／SSA／VTT 附件检测；不解包附件，无语言和可识别文件名的未知附件仍不能确认。
