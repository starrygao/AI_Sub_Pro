# 文件选择取消与 TMDB 识别修复

版本：修复首发于 1.3.40，当前已安装的 1.3.41 包含全部修复。

## 原因及修改

- 旧版原生文件选择返回空值时继续调用隐藏的浏览器 file input，实际复现为取消后再次打开选择窗。现在原生取消直接返回，并阻止选择窗未关闭时的重复调用；文件夹取消也不再误报不支持。
- `All.Creatures.Great.and.Small.2020.S06E07.Christmas.Special.2025...mkv` 被解析成剧名 `All Creatures Great and Small 2020`、首播年份 2025。TMDB 请求成功但没有结果。现在优先解析季集编号前的剧集身份年份；限定年份的电视剧搜索无结果时，尝试不限定年份的搜索，仍保留候选确认规则。
- HTTP 请求日志会包含 TMDB 查询密钥，已新增日志过滤；历史日志未修改。

## 验证

- 三个主要回归用例在修复前失败，修复后通过；日志遮蔽用例也先失败后通过。
- 161 项相关回归通过，另有 73 项项目及 TMDB 接口测试通过。
- 安装包和实际安装位置的启动、合成凭证写入、重启读取、删除测试均通过。
- 签名严格校验和 DMG SHA-256 校验通过；与 1.3.39 的签名身份相同。
- 在线 TMDB 搜索确认 2020 版《万物生灵》为 108255；项目 `6fee9fd8` 已恢复此关联和第 6 季信息，没有启动翻译。
- 实际安装的四个修改模块与工作区逐字节一致。
