## 最小软件修复

App 与 Docker 共用以下 Python 模块：

- `entity_registry.py`：一条原文有多个实体且缺少明确对应关系时，停止用唯一中文音译片段猜配。优先保留独立称呼、明确说话人标注的完整译名；有源文依据的全名/姓氏别名继续受支持。WIBC 等原样保留的缩写不再配给邻近人物。
- 明确译名不能匹配另一长姓名的一部分，如“弗雷德”不能取自“弗雷德里克”。`【电话】` 等声音场景标记也不能充当人物姓名；先去除场景标记再识别紧随其后的说话人。
- 常见语气词、匿名男女说话人不再进入实体候选，降低错误实体上下文传给模型的风险。
- `metrics.py` 传递源文中实际出现的全名别名，避免收紧规则后误报正常的姓氏简称。
- `translation_qa.py` 不再将一般 voice / woman's voice 当作旁白。明确电话、画外、narrator / voiceover 各自保持原规则。软件不会仅因女声就推断为电话；该成品电话标注来自人工上下文核对。

本次不更改模型、推理强度、账户、存储目录或新文件监控政策。这些防护针对已证实的错误对应与错误标签，不能保证解决所有影视隐喻、指代与画面依赖的翻译。
