# 服务器字幕校正与实体替换修复（2026-09-23）

## 已复现的根因与代码修复

`normalize_inferred_proper_name_variants` 以前会根据多数译文中的共同字串猜测待替换范围。实际任务中，Lady Chiyome 被错误关联到同句的地点“拉拉托亚”，导致地点变成人名；Hilk Church、Holy Hilk Kingdom 的猜测范围还会吃掉“得”“看来”。这不是更换翻译模型就能解决的问题：正确译文也会在模型处理之后被确定性后处理破坏。

本次仅收紧共用后处理器：只有具有边界证据、且在句内唯一出现的译名范围才可替换；不再从共同字串猜测范围；双方包含关系一律跳过，避免删除或添加称谓及周围对白；不同译法须共享至少两个不同汉字；前一次修改后，不再使用旧观察结果继续改写同一句。保留既有人工术语优先规则与严格多数要求。不能可靠判断的实体保留 QA 提示，不自动修改。

这是一项保守防护，不是完整实体对齐算法。当前 QA 本身仍可能将称谓差异或错误截取的字串标成疑点；没有因此隐藏提示、改变无人值守交付策略或承诺消除所有误报。
